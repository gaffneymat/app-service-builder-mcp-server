How it works: the page sends your question to the app's AI agent. The agent connects to the app's own MCP server (initialize, tools/list), offers those tools to the AI model, and runs every tools/call the model asks for until the model writes an answer. The model is Azure OpenAI, reached with the app's managed identity, so no key is stored anywhere. Outside MCP clients can use the same server at /mcp with the app token. Hosted on Azure App Service Builder (preview).
